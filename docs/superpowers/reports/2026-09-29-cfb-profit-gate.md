# CFB profit-model gate (2026-09-29)

Spec: `docs/superpowers/specs/2026-09-29-cfb-profit-model-design.md` §3–4. Tuning seasons [2019, 2020, 2021, 2022] (hyperparameters, Kelly policy, baseline policy); verdict seasons [2023, 2024, 2025] — never used for any choice.

- Prices: spread/total at -110 both sides (ruling P5); moneyline at the CFBD median closing moneylines. Openers and moneylines exist only from 2021 (ruling D1): tuning uses closes 2019–22 + openers 2021–22; moneyline tunes on the seasons it can be predicted in.
- A season counts for a market at a price point only with ≥ 70% coverage (moneyline: both moneylines).
- Bankroll starts at 100 units; stakes = fractional Kelly, ≤ 3 % per bet, ≤ 15 % per ET slate day; one side per game, market and price point.
- **Kelly ROI ($)** = `simulate` profit / dollars staked with the compounding bankroll. **Stake-unit ROI** = Σ stake_frac·P&L / Σ stake_frac (the unit the season-week cluster bootstrap CI uses; the ship rule's CI clause uses it). Flat $10 = the same bets at $10 each.
- Pushes (and voids) stay in the bet set — a bet is placed before the result is known — and settle at 0 with the stake returned; they count as bets and as staked and take up day-cap room. ECE, log-loss, the calibration deciles and the table's `rows` use the labelled rows only (pushes excluded).
- The ship rule's ECE is over ALL labelled combined-verdict rows at the primary price point, bet or not.
- Baseline = the ratings model's own Normal probabilities (sigmas 16.67 / 16.89) through the same policy, tuned the same way.
- The ship rule is judged at the **opener** for spread and total; CFBD has no moneyline opener, so the moneyline is judged at the **close**.
